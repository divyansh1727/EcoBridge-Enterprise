## ✨ Features

- JWT Authentication & OAuth2
- Role Based Access (Generator / Recycler / Admin)
- Waste Management
- Recycler Discovery
- Nearby Matching
- Analytics Dashboard
- Notifications
- Kafka Event Streaming
- Dockerized Microservices
- Kubernetes Deployment
- CI/CD using GitHub Actions
- Monitoring using Prometheus & Grafana
